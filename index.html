Four architecture pillars

Each pillar is labelled with its real status, so you know what runs today and what is still on the drawing board.

Zero-trust multi-tenant

Planned · v0.2+

PostgreSQL row-level security per tenant and an ephemeral sandbox per task, so agents only see what the card allows.

Hybrid Kanban & chat

In progress · v0.1

A versioned card-state contract and a LangGraph flow that pauses for human approval in Discord before opening a pull request.

Cognitive FinOps

Partial · v0.1

LiteLLM routing with cost recorded on every card today. Budget circuit breakers and a token ledger are planned.

Native MCP & AST RAG

Planned · v0.2+

v0.1 talks to GitHub through its REST API. Moving every integration to Model Context Protocol servers is next.

Roadmap

  1. Phase 0 — Foundation done

    Open-core repository, licensing, governance and the card-state contract.

  2. Phase 1 — Headless engine v0.1 in progress

    LangGraph orchestrator, LiteLLM routing, GitHub integration and human approval in chat.

  3. Phase 2 — Dogfooding planned

    v0.1 agents build the v0.2 web Kanban in public.

  4. Phase 3 — Enterprise planned

    SSO and RBAC, WhatsApp and Teams connectors, ROI dashboards.
